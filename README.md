# EcoLife Store

Eco-friendly e-commerce website built with WordPress and WooCommerce.

## About the Project

EcoLife Store is an e-commerce project focused on promoting environmentally friendly products and supporting efforts to reduce global warming.

## Features

- Product catalog with 20 eco-friendly products
- Shopping cart and checkout
- WooCommerce order management
- Cash on Delivery (COD) payment simulation
- Custom WordPress theme
- About and Contact pages

## Technology Stack

- WordPress
- WooCommerce
- PHP
- HTML
- CSS
- JavaScript

## Installation

1. Install WordPress on a local server using Laragon.
2. Install and activate WooCommerce.
3. Copy the `ecolife-custom` theme into `wp-content/themes/`.
4. Activate the theme from WordPress Dashboard.
5. Configure WooCommerce pages and products.

## Notes

This project is intended for local demonstration and educational purposes.
No live payment processing is configured.
